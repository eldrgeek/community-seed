# Install SOMA Guide

SOMA Guide is a Chrome extension. It shows a tip box on a web page that points at the next thing to click. It never clicks, types or submits for anyone. The person does every step.

You do not install it. You talk your person through it, one step at a time, and wait for them to say each step is done.

## Before you start

- Ask your person whether they use Google Chrome on a computer. SOMA Guide does not work on phones or in other browsers. If they do not use Chrome, stop and tell them.
- They need the SOMA Guide folder that was sent to them, as a zip file. If they do not have it, ask them to get it from the person who invited them. Never send them a download link you found yourself.

## Steps

Give one step, then wait for "done".

1. Unzip the SOMA Guide file. Inside is a folder called `dist`.
2. In Chrome, type `chrome://extensions` in the address bar and press Return.
3. Turn on "Developer mode", in the upper-right corner of that page.
4. Click "Load unpacked".
5. Choose the `dist` folder.
6. Open Chrome's Extensions menu (the puzzle piece) and pin SOMA Guide, so it stays visible.
7. Open the guide link they were sent. SOMA Guide's start page opens and shows its version number.

## If something goes wrong

- If Chrome says a guide's signature is invalid or the guide is unsigned, tell your person to stop and ask the sender for a new link. Never help them work around that warning.
- If Chrome asks to give SOMA Guide access to a site, your person should read the site name. They approve it only if it is the site they expect.
- Every tip box has a "Something's wrong" link. It sends a note to the SOMA team only when the person presses Send.

## Check

You did it right when the start page shows a version number, and your person made every click themselves.
